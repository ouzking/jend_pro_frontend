Supprimer votre compte JËND PRO

Pour demander la suppression de votre compte et des données personnelles associées :

  1. Dans l'application : Plus → Mon profil → Supprimer mon compte, puis envoyez l'e-mail pré-rempli ;
  2. ou par e-mail à ousmanearfangkemobodian@gmail.com, depuis l'adresse de votre compte, avec pour objet « Demande de suppression de compte JËND PRO ».

Ce qui est supprimé

  • votre compte (nom, e-mail, téléphone) et votre accès à tous les commerces ;
  • si vous êtes le seul propriétaire d'un commerce : les données de ce commerce (produits, ventes, clients, etc.).

Les données d'un commerce qui garde d'autres propriétaires restent accessibles à ceux-ci ; votre nom n'y apparaît plus. La suppression est effectuée sous 30 jours après vérification de votre identité, sauf obligation légale de conservation.
